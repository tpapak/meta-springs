Pairwise → fixed-effect NMA

Thodoris Papakonstantinou

The running example · fixed-effect spring network

The 4-treatment continuous network that runs through the whole series. Springs start at their natural length — the raw within-study effects; press Link studies and the shared treatment nodes glue into one column each, the springs stretch, and the network settles into the inverse-variance estimate.

Pairwise meta-analysis is two springs

Take one study comparing treatment $B$ to $A$ with observed effect $y_i$ and variance $v_i$. Put a node on a 1-D effect axis and connect it to the pooled effect $d$ by a spring of natural length $y_i$ and hardness $k_i = 1/v_i$. The equilibrium position of $d$ minimises the total elastic energy

$$ E(d) = \sum_i \tfrac{1}{2}\,k_i\,(d - y_i)^2 \;\Rightarrow\; \hat d = \frac{\sum_i k_i\,y_i}{\sum_i k_i}, $$

which is exactly the inverse-variance fixed-effect estimate: a stiffer spring (more precise study) pulls the pooled effect harder. Meta-analysis is a force balance.

Fixed-effect NMA is a bipartite spring network

A network has $T$ treatments and $S$ studies. Give every treatment a node $d_t$ on the effect axis (reference pinned at $d_{\text{ref}}=0$) and every study a baseline node $\mu_i$. Each arm $(i,t)$ is an observation spring from the study to the treatment node, natural length $y_{it}$, hardness $1/v_{it}$. The network is bipartite — study nodes on one side, treatment nodes on the other, springs across — and its equilibrium $\arg\min_{\mu,d} \sum_{it} \tfrac{1}{2v_{it}}(\mu_i + d_t - y_{it})^2$ is the generalised-least-squares / consistency NMA estimate. Multi-arm trials are just studies whose baseline node carries several springs — this is the network in the animation above; press Link studies there to watch it settle.

Code

meta-springs (R — gemtc-shaped facade)

library(springs)                       # drop-in for the gemtc slice
data(smoking, package = "gemtc")
net <- mtc.network(smoking$data.ab)
fe  <- mtc.run(mtc.model(net, likelihood = "binom",
                         link = "logit", linearModel = "fixed"))
summary(fe)$summaries$statistics       # d.A.B, d.A.C, ...  (closed form, no MCMC)

multinma (R)

library(multinma)
net <- set_agd_arm(smoking, study = studyn, trt = trtn,
                   r = events, n = sampleSize)
fe  <- nma(net, trt_effects = "fixed",
           prior_intercept = normal(0, 100),
           prior_trt       = normal(0, 100))   # MCMC
summary(fe)
