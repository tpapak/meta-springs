Baseline-risk network meta-regression — the honest spring network

The treatment effect is regressed on each trial's own baseline risk (control-arm log-odds, the latent node ηi), the Achana 2013 / bnma model MetaInsight uses. Each study is a point hanging from its treatment's shared-slope line by a spring of stiffness = arm information. The line is effect = dt + B·(ηi−mx); drag B to feel the springs — the total energy (Σ stiffness·gap²) is minimised at the fitted slope. Self-referential: ηi sets both a point's x-position and enters its effect — the rod ties to the node, not to an external covariate.

x = baseline log-odds ηi (left = low control risk, right = high)  ·  y = treatment effect (log-OR vs control)  ·  dashed vertical = centering mx; reported dt is the effect there.
Shared node = randomization: both arms of a trial attach to one ηi — the treated group, untreated, would share the control's baseline. A non-zero B is a study-level (ecological) association: genuine effect-modification, scale compression, and trial-conduct/blinding artefacts are not separable.
