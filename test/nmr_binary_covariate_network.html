Network Meta-Regression: the spring network

The actual node-link spring system (force-directed). Treatment nodes A, B, C; small covariate-level nodes b₀,b₁,c₀,c₁; the shared β node; and study nodes Si. Obs springs tie studies to their arms; β springs tie every covariate-level node to the one β node (so one β node serves all levels).
Drag-free force layout: springs pull connected nodes together, all nodes repel so the wiring spreads out. See how each study connects to its two arms (reference A, and a covariate-level node for the active arm), how each level node hangs off its treatment, and how all level nodes converge on the single β node — that hub is the shared regression coefficient. Unrelated splits it into one β node per treatment; Pooled drops the covariate nodes entirely.
