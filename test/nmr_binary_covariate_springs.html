Network Meta-Regression: the β node on the effect axis

Same 1-D grammar as the Ξ animation: every node sits on one effect axis and every spring is horizontal. 3 treatments (A = reference, B, C), 6 studies, binary covariate x ∈ {0,1}. Each non-reference treatment has a base node (effect at x=0) and a covariate node (effect at x=1). The covariate node is reached from the base node by a spring whose length is β, and all those springs share one β node — β is the network-mean covariate shift, just as a treatment effect is the network-mean of its evidence.
