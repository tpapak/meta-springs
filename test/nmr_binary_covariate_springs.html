Network Meta-Regression: arm-level spring system

Same grammar as the Ξ animation, with a covariate. Standard NMA convention yij = μi + (dj + β·xi) + δij. Study spindles Si sit at the centroid μ̂i; each arm has a τ-chain to its BLUP node δij and an obs spring to its base column dj. The covariate is centred, so each treatment's capital base node (B, C) is the effect at the mean covariate and its two lowercase covariate nodes (b0, b1) sit symmetrically at dj ∓ β/2. A non-reference arm then continues in series along a β spring from the base column to the covariate node where it sits — every β spring shares the one β node (top).

Vertical columns through the study rows = effect nodes: solid capital = base node dj (effect at the mean covariate); dashed lowercase = the two symmetric covariate levels dj∓β/2 (b0 = x = 0 on the left, b1 = x = 1 on the right). x=0 arms land on b0, x=1 arms on b1. Reference A is pinned (dA=0) and has no covariate node. Each non-reference arm's obs spring lands on the base column dj, then a β spring carries it in series to the covariate node dj∓β/2 where the arm sits — and every β spring shares the one β node (all horizontal, parallel). Pooled drops β (one network); Unrelated frees each βt. Raise τ² and the BLUP nodes slide out along the τ-chains while the obs springs relax — τ² is now residual heterogeneity after regression.
