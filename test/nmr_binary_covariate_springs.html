3 treatments (A = reference, B, C), 6 studies, binary study-level covariate x ∈ {0, 1} (e.g. 0 = short follow-up, 1 = long follow-up), outcome = log-OR. Each covariate level is its own sub-network of real treatment nodes. The covariate springs (orange) couple a treatment's two layer-nodes through a shared β node — that coupling is what carries the regression coefficient, and the x = 1 study springs are what load it.

Coloured coils = studies (precision 1/(vi+τ²), natural length = observed log-OR), each inside its own covariate layer. Lower band = x = 0, upper band = x = 1 — both hold genuine, free treatment nodes. Orange covariate springs tie each active treatment's two layer-nodes to the shared β node (diamond); the reference A is pinned at 0 in both layers so it has no covariate spring. Shared forces one common β (stiff coupling); Unrelated cuts the coupling so each layer is its own NMA (per-treatment βt); Pooled clamps the gap to 0 (β=0) and the study coils strain — one network can't fit both groups.
