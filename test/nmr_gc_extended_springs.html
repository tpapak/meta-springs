Extended spring network: grand-canonical example + covariate

The Ξ-animation network (4 treatments A–D; 2-, 3- and 4-arm studies), extended with a binary covariate and drawn fixed-effect (tau springs omitted). Convention yij = μi + (dj + β·xi). Each arm is two springs in series meeting at a base node ● (filled dot on the treatment column): the study/obs spring (spindle → base node) and, for active arms, a β spring that branches off the base node down to the covariate node dj±β/2. No tau node — residuals show as obs-spring stretch.
β = 0.000
Solid columns = base treatment effect dj (at mean covariate); small dashed nodes = covariate levels dj∓β/2. Reference A is pinned at 0. The shared β node (top) sets the length of every β spring. Tau springs are left out — add them back and each arm would gain a τ-chain to a BLUP node (heterogeneity).
