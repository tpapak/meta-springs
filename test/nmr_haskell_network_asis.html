The makeSprings network + the β extension (nmaRegression)

Base network verbatim from Data.Meta.NMA.makeSprings (S1:(A=0.40,B=1.80,x=1), S2:(A=−0.80,C=1.20,x=2), S3:(B=0.90,C=2.10,x=3); sd=2,n=100 ⇒ 1/v=25). The β node is the network meta-regression extension now implemented in nmaRegression: each non-reference arm couples to β with lever ×xᵢ (the study covariate), i.e. its treatment end sits at dt+β·xᵢ. Reference (A) arms have no β coupling.
StudyEnd (μi), TreatmentEnd (every treatment incl. reference), TauEnd (one per arm, τ>0 only). Each edge is a Spring k ℓ₀ ℓ: FE = one obs spring per arm StudyEnd→TreatmentEnd (k=1/v, ℓ₀=arm mean); RE = StudyEnd→TauEnd (k=2/τ², ℓ₀=0) then TauEnd→TreatmentEnd (k=1/v, ℓ₀=arm mean). ⚓ = pinned vertex (gauge).
