Network meta-regression: the spring network for every model

Each NMA/NMR model is a spring network. Reading order = increasing structure: standard NMA → add a regression rod → add heterogeneity (τ springs) → split the slope per treatment → tie the slopes with slope-springs (a second variance component) → swap the spring force law for continuous data. Covariate regression has a fixed-length rod to an external value; baseline-risk regression's rod is self-referential — it ties to the study's own baseline node (the bilinear coupling).
